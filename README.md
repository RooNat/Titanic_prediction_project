## **Titanic - Machine Learning from Disaster**

This project is based on the Kaggle competition [**Titanic - Machine Learning from Disaster**](https://www.kaggle.com/competitions/titanic).

I built several machine learning models — including **KNN**, **Random Forest**, and **Logistic Regression** — to predict passenger survival.

The final model achieved an **accuracy of 82.775%** on the test set, ranking **295th out of 14,413** teams on Kaggle.

After excluding submissions that used the ground truth, the model would be in the **top 1%** of genuine competitors.

* [**Advanced\_Feature\_Engineering.ipynb**](Advanced_Feature_Engineering.ipynb) – Initial data exploration and a baseline Random Forest model.
* [**titanic\_final.ipynb**](titanic_final.ipynb) – Final model development and prediction results.
